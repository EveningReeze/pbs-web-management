# 个人博客系统（全栈项目）

## 一、 项目简介
本项目是一个基于 **前后端分离架构** 的个人博客管理系统。系统旨在为博客作者提供一个直观、高效的内容管理平台，不仅包含博客文章的全生命周期管理（撰写、发布、分类、标签），还提供了数据可视化看板，帮助作者实时掌握博客运营状态。同时，系统预留了音乐管理等拓展模块。

## 二、 技术选型

### 前端技术栈
*   **核心框架：** Vue.js 3 (Composition API) + Vite
*   **UI 组件库：** Element Plus
*   **状态管理：** Pinia
*   **路由管理：** Vue Router
*   **数据可视化：** ECharts
*   **富文本编辑器：** WangEditor / TinyMCE
*   **网络请求：** Axios (封装了统一的请求拦截与响应处理)

### 后端技术栈（基于常规博客系统架构推测/补充）
*   **核心框架：** Node.js (Express/Koa/NestJS) 或 Java (Spring Boot)
*   **数据库：** MySQL (关系型数据) + Redis (缓存热点数据及浏览量)
*   **ORM 框架：** Sequelize / TypeORM / MyBatis-Plus
*   **身份认证：** JWT (JSON Web Token) 实现无状态登录鉴权
*   **文件存储：** 阿里云 OSS / 腾讯云 COS / 本地静态资源服务器（用于存储文章封面及富文本图片）

## 三、 核心功能模块

### 1. 数据可视化看板 (Dashboard)
*   **数据概览：** 顶部卡片展示核心指标（总文章数、总浏览量、分组数量、标签数量）。
*   **图表统计：**
    *   柱状图：展示各分组（如已发布、未发布）的文章数量分布。
    *   环形图：展示各标签（如 Vue、前端、Node）的文章使用占比。
*   **后端支撑：** 提供聚合统计 API，通过 SQL 聚合查询（`COUNT`, `GROUP BY`）或 Redis 计数器，快速返回看板所需的核心数据。

### 2. 文章管理模块 (Article Management)
*   **文章列表：** 支持按状态（全部/已发布/未发布）、标签进行多维筛选，支持关键词模糊搜索。
*   **文章操作：** 提供文章预览、编辑、删除功能。
*   **文章发布/编辑：**
    *   表单录入：标题（带字数统计）、分组选择、标签绑定、简介填写。
    *   封面上传：支持图片格式与尺寸校验，上传至云端或本地服务器。
    *   富文本编辑：集成功能丰富的编辑器，支持多媒体插入、代码块、表格等复杂排版。
*   **后端支撑：** 提供文章的 RESTful API（增删改查）。处理富文本内容的安全过滤（XSS 防护），处理图片上传接口，并维护文章与标签的多对多关联关系。

### 3. 分类与标签管理 (Category & Tag)
*   **分组管理：** 支持自定义文章分组（如：技术分享、生活随笔等）。
*   **标签管理：** 支持标签的创建、修改与删除。文章发布时可多选标签。
*   **后端支撑：** 提供独立的分类和标签 CRUD 接口，并在删除标签时处理与文章的关联关系（如级联删除或解除关联）。

### 4. 系统与用户模块 (System & User)
*   **登录鉴权：** 管理员登录后获取 Token，后续请求携带 Token 进行权限校验。
*   **退出登录：** 清除本地 Token，跳转至登录页。
*   **后端支撑：** 实现用户登录接口，校验密码（加密存储），签发 JWT。编写全局中间件拦截未授权请求。

## 四、 项目亮点

1.  **前后端分离与接口规范：** 前后端通过 RESTful API 进行通信，数据格式统一为 JSON，降低了前后端耦合度，便于独立开发和部署。
2.  **数据可视化驱动：** 引入 ECharts 实现运营数据的直观展示，后端通过高效的聚合查询提供数据支撑，帮助作者掌握博客动态。
3.  **沉浸式创作体验：** 前端集成强大的富文本编辑器，后端提供稳定的图片上传与存储服务，满足复杂的博客写作与排版需求。
4.  **组件化与工程化：** 前端对图表、表单、列表等进行了高度组件化封装；后端采用分层架构（Controller-Service-DAO），代码结构清晰，易于维护和扩展。
5.  **性能优化：** 针对文章浏览量等高并发读写操作，后端可引入 Redis 进行计数缓存，定期同步至 MySQL，减轻数据库压力。

## 五、 项目结构（参考）

```text
pbs-web-management/          # 前端项目
│   ├── src/
│   │   ├── api/            # Axios 接口封装
│   │   ├── assets/         # 静态资源
│   │   ├── components/     # 公共组件 (如富文本编辑器、图表组件)
│   │   ├── layout/         # 整体布局 (侧边栏、顶部导航)
│   │   ├── router/         # 路由配置
│   │   ├── store/          # Pinia 状态管理
│   │   ├── views/          # 页面视图 (看板、文章列表、发布文章)
│   │   └── App.vue
│   └── vite.config.js


pbs-management-system/           # 后端项目
    ├── src/
    │   ├── config/         # 数据库、Redis、OSS 配置
    │   ├── controllers/    # 控制器 (处理 HTTP 请求)
    │   ├── services/       # 业务逻辑层
    │   ├── models/         # 数据库实体模型
    │   ├── routes/         # 路由定义
    │   ├── middlewares/    # 中间件 (鉴权、错误处理)
    │   └── utils/          # 工具类 (JWT, 文件上传)
    ├── app.js              # 应用入口
    └── package.json
```
